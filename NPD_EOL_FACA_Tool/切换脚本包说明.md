# 台式机切换到脚本包(方案 A)

> 目的:把台式机从"单文件 exe"切换为"脚本包"(run_verify.bat 启动),
> 之后每次改代码只需拷一个补丁文件夹,不再反复打包/下载 exe。

## 一、首次切换(只做一次)

### 1. 拿部署包

方式一(推荐):直接拷贝本机/开发机的部署包目录:

```
C:\SN_Report_pkg\     ← 整目录拷贝 package_oracle_verify\ 的内容
```

方式二:从 GitHub 下载代码 zip(不含 exe),解压后用其中的
`sn_report\package_oracle_verify\` 目录。

**注意**:不要下载 Actions 里的 `SN_Report-exe` artifact —— 那是 exe 版。
脚本包长这样(纯脚本,零 exe):

```
C:\SN_Report_pkg\
├── run_verify.bat          ← 双击这个启动(不是 exe)
├── python311.tar.gz        ← 便携 Python 3.11(首次运行自动解压)
├── instantclient\          ← Oracle Instant Client 19.13
├── wheels\                 ← 全部离线依赖
├── requirements.txt
├── oracle_download\
│   ├── run_oracle_download.py
│   ├── conns.json          ← 需要手动放置(见下)
│   └── lib\                ← oracle_client / rayprush_auth / login_dialog 等
└── sns.txt                 ← 每行一个 Module SN
```

### 2. 放连接配置(唯一含密码文件,不走 git)

把开发机的 `reference\lth\cimtool_conns_decrypted.json` 拷为:

```
C:\SN_Report_pkg\oracle_download\conns.json
```

### 3. 编辑 SN 列表

`C:\SN_Report_pkg\sns.txt`,每行一个 Module SN。

### 4. 运行

双击 `C:\SN_Report_pkg\run_verify.bat`:

1. 自动解压便携 Python 3.11(Windows 10 1803+ 自带 tar)
2. 自动解压 Instant Client
3. 离线安装 wheels(仅首次)
4. 弹出 Rayprush 一账通登录验证(10.151.128.45:8081,通过才继续)
5. 逐 SN 查询/下载全部站位照片
6. 输出 `oracle_download\output\oracle_verify\<时间戳>\`(verify.json + run.log)

## 二、后续迭代(改代码 → 补丁,不再打包)

### 开发机(我这边)

改完代码后生成补丁:

```bat
python sn_report\package_oracle_verify.py
python sn_report\make_patch.py -m "修复 xxx"
```

产物:`sn_report\patches\patch_<时间戳>\`(只含变更文件)。

### 台式机(你这边)

1. 把 `patch_<时间戳>\` 整个目录拷到 `C:\SN_Report_pkg\` 下;
2. 双击 `patch_<时间戳>\apply_patch.bat`;
3. 完成,直接重跑 `run_verify.bat` 即可,无需任何下载/安装。

已应用补丁记录在 `C:\SN_Report_pkg\.applied_patches.json`。

## 三、验证闭环

1. 台式机跑完 → 拷回 `oracle_download\output\oracle_verify\` 与 `downloads\`;
2. 开发机分析 verify.json(每 SN × 每站查询/下载明细、错误);
3. 改代码 → `make_patch.py` → 台式机应用补丁 → 继续测试。
