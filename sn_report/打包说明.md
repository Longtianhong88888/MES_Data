# SN_Report Windows 打包说明（供审查）

> 目标：把一个 PyQt5 图形界面程序打包成 Windows 免安装 onedir 程序
> （`SN_Report.exe` + `_internal\`，双击即用），通过 GitHub Actions 云端构建。

---

## 1. 项目结构与依赖关系

### 源码文件（`sn_report\` 下）

| 文件 | 作用 | 是否参与打包 |
|---|---|---|
| `gp_gui.py` | **入口**：PyQt5 主窗口，SN 输入/文件上传/下载/日志 | ✅ 入口脚本 |
| `run_gp_download.py` | 核心逻辑：Greenplum 查询（专案识别、EOL/FOL 图片提取、域名→IP 下载） | ✅ 被 gp_gui 导入 |
| `excel_report.py` | 图片导出 Excel（行=站位，列=SN，多图合并行，JPEG 转换） | ✅ 被 gp_gui 导入 |
| `apple_style.py` | Apple 风格 QSS 主题 + 卡片工具函数 | ✅ 被 gp_gui 导入 |
| `favicon.ico` | 窗口图标 + exe 图标 | ✅ 数据文件 |
| `build_exe_onedir.bat` | 本地打包脚本（任意联网 Windows 机器） | 打包机用 |
| `run_oracle_download.py` 等 | 旧版 Oracle 直连脚本（已弃用，不再打包） | ❌ 不打包 |

```

```

### 运行时 Python 依赖（pip 包，必须在打包环境安装）

```
PyQt5
```

> 也无害；建议移除避免误解。

## 2. 数据资源

### favicon.ico（必须）

- 位置：`sn_report\favicon.ico`（256x256 ICO）
- 用途：
  1. PyInstaller `--icon` → exe 文件图标
  2. `--add-data` → 运行时窗口图标（`gp_gui.py` 从 `BASE_DIR` 或 `sys._MEIPASS` 读取）

### config.json（可选，运行期）

- 位置：exe 同目录 `config.json`（不存在则用内置默认值）
- 内容：数据库连接（host/port/database/user/password），默认指向 Greenplum
- 不参与打包，运行期由 `gp_gui._load_db_config()` 读取

## 3. 打包方式（两种，二选一）

### 方式 A：GitHub Actions（推荐）

配置文件：`.github/workflows/build_exe.yml`

触发方式：push tag `v*` 或手动 workflow_dispatch

关键步骤：
1. `setup-python@v5`，Python 3.10（Windows x64）
2. `pip install pyinstaller pg8000 scramp requests PyQt5 openpyxl Pillow`
3. PyInstaller 命令：
   ```
   python -m PyInstaller --noconfirm --clean --onedir --windowed ^
     --name SN_Report ^
     --paths sn_report ^
     --icon "$repo\sn_report\favicon.ico" ^
     --add-data "$repo\sn_report\favicon.ico;." ^
     --hidden-import pg8000.native ^
     --hidden-import scramp ^
     --hidden-import gp_gui ^
     --hidden-import apple_style ^
     --hidden-import openpyxl ^
     --hidden-import excel_report ^
     --distpath dist ^
     --workpath build ^
     --specpath build ^
     sn_report\gp_gui.py
   ```
4. 上传 artifact：`dist/SN_Report` 整个目录
5. push tag 时自动建 Release，附 `SN_Report.exe`

### 方式 B：本地 Windows 打包

`sn_report\build_exe_onedir.bat`：找 Python → 装依赖 → 同上 PyInstaller 命令 →
产物 `sn_report\dist\SN_Report_Windows\`。

## 4. 历史踩坑记录（审查重点，必须避免复发）

### 4.1 缺依赖导致 exe 运行报错

**坑**：`excel_report.py` 用 openpyxl/Pillow，但打包环境只装了
pg8000/scramp/PyQt5 → exe 运行报 `ModuleNotFoundError: No module named 'openpyxl'`。

**规则**：打包环境安装的 pip 包 = 入口模块依赖的**全集**（含传递依赖），
每新增一个 import 必须同步更新：
- `.github/workflows/build_exe.yml` 的 `pip install`
- `sn_report/build_exe_onedir.bat` 的 `pip install`

### 4.2 favicon 相对路径被 PyInstaller 按 spec 目录解析

**坑**：`--add-data "sn_report/favicon.ico;."` 相对路径会被解析成
`build\sn_report\favicon.ico`（spec 目录），构建报
`Unable to find ... favicon.ico`。

**规则**：`--icon` 和 `--add-data` 必须用**绝对路径**（Actions 里用 `$repo` 前缀，
bat 里用 `%REPO_ROOT%` 前缀）。

### 4.3 PyInstaller frozen 路径

**规则**：打包后 `__file__` 指向 `_internal`，代码里必须用
`sys.executable` 所在目录作为 BASE_DIR（输出/日志/下载都放 exe 旁边）。
`gp_gui.py`、`run_gp_download.py` 均已处理。

### 4.4 bat 闪退（Windows）

**规则**：Windows bat 必须：无 BOM + 纯 ASCII + CRLF 行尾；
中文注释会因代码页解析失败闪退。

### 4.5 图片域名解析失败

**规则**：图片 URL 用内网域名（cma1.fs.com 等），内网 DNS 不解析时必须
替换为代理 IP（`run_gp_download.DOMAIN_IP_MAP`）。

## 5. 审查清单

请 Claude 重点审查：

1. **依赖完整性**：入口模块的所有 import（含间接）是否都在 workflow/bat 的
   `pip install` 里？有没有遗漏 openpyxl/Pillow/et_xmlfile/scramp？
2. **hidden-import**：`--hidden-import` 是否覆盖所有非入口导入的本地模块
   （gp_gui/apple_style/excel_report）和动态导入（pg8000.native）？
3. **路径**：`--icon`/`--add-data` 绝对路径；运行时 BASE_DIR frozen 处理。
4. **数据文件**：favicon.ico 是否已提交、路径是否正确。
5. **windowed 模式**：GUI 程序必须 `--windowed`（否则弹控制台黑框）。
6. **依赖版本**：Python 3.10 + PyInstaller 当前版本兼容性。

## 7. 审查结果（2026-08-11）

> 以下为对照实际代码和配置文件进行审查后发现的问题，按严重程度排列。

### 🔴 严重

#### 7.1 Release 步骤只上传 `SN_Report.exe`，缺少 `_internal/` 运行时目录

**位置**：[`.github/workflows/build_exe.yml:59-64`](../.github/workflows/build_exe.yml#L59-L64)

```yaml
- name: Release
  with:
    files: |
      dist/SN_Report/SN_Report.exe
```

Release 只附加了一个 `.exe` 文件，**没有**打包整个 `_internal/` 目录。用户从 GitHub Release 页面下载后，exe 无法独立运行（详见第 6 节"必须整体拷贝，不能只拷 exe"）。artifact 上传里有完整目录，但 Release 不给用户。

**修复建议**：将整个 `dist/SN_Report/` 打包成 zip，或使用通配符 `dist/SN_Report/**`。

---

### 🟠 中等

#### 7.2 bat 缺少 `--hidden-import apple_style`

**位置**：[`sn_report/build_exe_onedir.bat:47-55`](build_exe_onedir.bat#L47-L55)

`gp_gui.py:64` 明确导入 `from apple_style import APPLE_QSS, C_BG, C_SUB, card, hint`，workflow 中有 `--hidden-import apple_style`，但 bat 文件**没有**。虽然 PyInstaller 多数情况下能自动追踪到，但如果解析失败，运行时会报 `ModuleNotFoundError`。第 5 节审查清单第 2 条明确要求 hidden-import 覆盖所有本地模块。

#### 7.3 bat 与 workflow 的 PyInstaller 参数不一致

| 参数 | workflow | bat |
|---|---|---|
| `--hidden-import apple_style` | ✅ 有 | ❌ 缺失 |
| `--hidden-import lib.config` | ❌ 没有 | ✅ 有 |
| `--hidden-import lib.rayprush_auth` | ❌ 没有 | ✅ 有 |
| `--collect-submodules PyQt5` | ❌ 没有 | ✅ 有 |

进一步排查发现：`lib.config` / `lib.rayprush_auth` **仅被已弃用的 `run_oracle_download.py` 引用**，Greenplum 代码路径 (`gp_gui.py` → `run_gp_download.py` + `excel_report.py`) 并不导入它们。bat 中这些 hidden-import 属于遗留复制错误——虽然无害，但说明两边脚本不是在同一个模板上维护的。

#### 7.4 bat 中 `--icon` 和 `--add-data` 使用相对路径

**位置**：[`sn_report/build_exe_onedir.bat:45-46`](build_exe_onedir.bat#L45-L46)

```bat
--icon sn_report\favicon.ico
--add-data "sn_report\favicon.ico;."
```

第 4.2 节明确记录了"相对路径被 PyInstaller 按 spec 目录解析"的历史踩坑，要求**必须用绝对路径**。虽然 bat 先执行了 `cd /d "%~dp0.."` 切到项目根，但 `--specpath` 设为 `sn_report\build`，PyInstaller 的相对路径解析行为仍然不确定，可能在特定环境下复现找不到文件的错误。workflow 已正确使用 `$repo` 绝对路径，bat 应同步。

---

### 🟡 轻微

#### 7.5 `requests` 包安装但未使用

第 1 节已自行指出（"requests 当前代码未使用…建议移除避免误解"），但 bat 和 workflow 的 `pip install` 命令中**都没有移除**。浪费 CI 构建时间，也可能让审查者困惑。确认：`gp_gui.py`、`run_gp_download.py`、`excel_report.py` 均无 `import requests`。

#### 7.6 无 `requirements.txt` 统一管理依赖

依赖列表在 bat（第 31 行）和 workflow（第 26 行）两处硬编码，没有 `requirements.txt` 作为单一事实来源。这正是第 4.1 节记录的坑——每新增一个 import 必须同时改两处，遗漏风险高。建议创建 `requirements.txt`，两处统一改用 `pip install -r requirements.txt`。

#### 7.7 bat 结尾 `pause` 会阻塞自动化构建

**位置**：[`sn_report/build_exe_onedir.bat:62`](build_exe_onedir.bat#L62)、[`73`](build_exe_onedir.bat#L73)

```bat
pause
```

错误退出和成功完成路径都有 `pause`。如果有人在 CI 或其他自动化流程中调用这个 bat，`pause` 会导致流程无限挂起等待按键。建议改为仅在交互式运行时 pause（或直接移除）。

#### 7.8 文档路径分隔符不一致

第 4.2 节写成 `--add-data "sn_report\favicon.ico;."`（反斜杠），但同页其他示例多使用正斜杠。workflow 中实际使用的是 `$repo\sn_report\favicon.ico`（pwsh 环境可接受）。建议文档统一使用正斜杠 `/`，避免跨平台歧义。

---

### 📋 审查总结

| 类别 | 数量 | 关键项 |
|---|---|---|
| 🔴 严重 | 1 | Release 产物不完整（缺 `_internal/`） |
| 🟠 中等 | 3 | bat 缺 `apple_style` hidden-import；参数与 workflow 不一致；相对路径风险 |
| 🟡 轻微 | 4 | `requests` 多余；缺 `requirements.txt`；`pause` 卡自动化；路径分隔符不统一 |

**首要修复**：Release 步骤必须包含完整的 `_internal/` 目录，否则用户从 Release 下载后程序无法运行。其次应统一 bat 与 workflow 的 PyInstaller 参数，消除 drift 风险。
